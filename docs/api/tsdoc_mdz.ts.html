tsdoc_mdz.ts

Bridge between TSDoc format and mdz for rendering.

This module converts raw TSDoc syntax (from the analysis library) to mdz format (Fuz's documentation rendering dialect). It lives here in @fuzdev/mdz, not the svelte-docinfo analysis library, to keep that library format-agnostic.

mdz_from_tsdoc(content: string): string

Convert raw TSDoc @see content to mdz format for rendering.

Handles TSDoc link syntax:

  • {@link url|text} → [text](url) (markdown link, TSDoc canonical form)
  • {@link url text} → [text](url) (TS-lenient space-separated form)
  • {@link https://...} → https://... (bare URL, auto-linked by mdz)
  • {@link identifier} → the identifier as a code span
  • Bare URLs → returned as-is
  • Bare markdown links ([text](url) ...) → returned as-is
  • Content that opens with a backtick (a code span, then description text) → returned as-is
  • Bare identifiers → wrapped in backticks
  • identifier description text → the first token wrapped in backticks, the rest as written
import {mdz_from_tsdoc} from '@fuzdev/mdz/tsdoc_mdz.js';

parameters

content
: string
#

raw @see tag content in TSDoc format

returns

mdz-formatted string ready for Mdz component

examples

mdz_from_tsdoc('{@link https://fuz.dev|API Docs}') // → '[API Docs](https://fuz.dev)' mdz_from_tsdoc('{@link SomeType}') // → '`SomeType`' mdz_from_tsdoc('https://fuz.dev') // → 'https://fuz.dev' mdz_from_tsdoc('[svelte-docinfo](https://github.com/fuzdev/svelte-docinfo) for the analysis library') // → '[svelte-docinfo](https://github.com/fuzdev/svelte-docinfo) for the analysis library' mdz_from_tsdoc('tome.ts for the documentation system') // → '`tome.ts` for the documentation system' mdz_from_tsdoc('`tome.ts` for the `Tome` type') // → '`tome.ts` for the `Tome` type'
